# L'AMI Frontend

Next.js **16.3.4** (Active LTS) + React 19 + Tailwind + Zustand.

## Prerequisites

- Node.js **20.9+**

## Scripts

```bash
npm install
npm run dev          # Turbopack (recommandé)
npm run dev:webpack  # Webpack classique
npm run build
npm run start
npm run typecheck
```

## Env

```
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
